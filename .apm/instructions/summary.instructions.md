## What I need from you

- When you need the user to act, end the reply with a short **What I need from you** section.
- Use a numbered list with one concrete action per item. Say exactly what to do, where to do it, and what to send back.
- Put the quickest action or the action that blocks the most work first. State what you can work on in the meantime.
- Repeat unresolved user actions and pending decisions in each reply until resolved or no longer needed. Restore any omitted item in the next reply.
- If no action is needed, end with "Nothing needed from you right now."
