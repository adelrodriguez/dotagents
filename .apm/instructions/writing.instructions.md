# Write clearly

- Lead with the conclusion or result.
- Prefer plain, everyday words.
- Use periods or commas instead of em dashes. Do not substitute other dashes or parentheses.
- Use periods instead of semicolons.
- Use sentence-case headings.
- Omit chatbot phrases and sycophantic praise.
- Match certainty to the evidence. State what remains unverified.
- Write whole sentences with articles and verbs. Avoid compressed fragments and staccato prose.
- Keep one idea per sentence. Combine related short sentences when they develop one idea, and split sentences that require backtracking.
- Name the actual file, command, symbol, or project term.
- For vague attributions, name the source or delete.
- State the action or result directly. Avoid comparisons to alternatives the reader never raised.
- State each point once. Cut closing summaries that repeat the opening without adding information.
- Make "it," "this," and "they" refer to one clear thing. Repeat the noun when needed.
- Prefer active voice and name the actor. Passive is fine only when the actor is unknown or genuinely doesn't matter.
